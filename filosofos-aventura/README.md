# El Salón de las Ideas — Vercel

## Publicar gratis

1. Subí esta carpeta a un repositorio nuevo de GitHub.
2. En Vercel elegí **Add New → Project** e importá ese repositorio.
3. Antes de desplegar, abrí **Environment Variables** y agregá:

   - Key: `GROQ_API_KEY`
   - Value: tu clave de Groq

4. Tocá **Deploy**.

La web queda en la URL que Vercel te entrega. La API queda en:

`https://tu-proyecto.vercel.app/api`

No subas tu clave a GitHub ni la pegues en archivos del proyecto.
